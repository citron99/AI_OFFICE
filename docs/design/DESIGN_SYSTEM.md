## Компоненты и поведение

- Sidebar: четыре существующих раздела; активный обозначен также aria-current.
- На рабочем столе — переход к согласованиям, метрики, форма и список задач.
- Фильтр задач: все / в работе / нужно внимание. Поиск по ID и категории
  в последних загруженных 50 задачах, не глобальный серверный поиск.
- Реестр счетов: поиск по ID, номеру и контрагенту среди загруженных записей.
- Статусы: текст + маркер + семантический цвет. Нет случайных процентов прогресса.
- Согласование: native dialog.showModal(), изоляция фокуса браузером, возврат
  фокуса, Escape вне отправки решения, ошибка и загрузка внутри диалога.
- Поля отправленной задачи фиксируются; безопасный повтор и явная новая задача
  работают как раньше. Юридические уточнения независимы от исходной формы.
- Источники и аудит раскрываются по запросу, важные предупреждения не спрятаны.
- Финансы: денежный поток явно отделён от прибыли; значения только из API.

## Адаптивность

Две колонки рабочего стола на широком экране; одна при ширине до 1150px.
До 720px навигация переходит наверх, метрики становятся строками, таблицы
прокручиваются внутри контейнера, поля используют шрифт 16px.
Основные кнопки и поля не ниже 44px. Есть ссылка пропуска навигации.

## Проверки и границы

- Автотесты проверяют контраст основных пар токенов не ниже 4.5:1,
  наличие reduced-motion/focus-правил, фильтры и идемпотентную отправку.
- Сборка проверяет JSX/CSS; live smoke проверяет API через frontend proxy.
- Выполнена ручная браузерная проверка desktop и мобильного viewport 390×844:
  основной рабочий стол, бухгалтерия, согласования, источники, responsive
  навигация, доступные имена и отсутствие ошибок консоли. Информационный баннер
  перенесён ниже основного рабочего потока, чтобы форма была видна раньше.
- Второй проход выполнен с локальным read-only UI fixture: содержательные задачи,
  счёта, ожидающее согласование, источник и результаты трёх агентов. Проверены
  поиск+фильтр, native dialog, начальный фокус и возврат фокуса. Выбор задачи
  теперь мгновенно прокручивает к результату и не повторяет прокрутку при polling.
- Технические значения риска, policy, достаточности и агентов локализованы в UI;
  значения API и аудита при этом не изменяются.
- Screen reader остаётся непроверенным. Живой Docker-контур повторно проверен 2026-08-29:
  данные API отображаются, завершённый результат открывается, ошибок консоли нет; сквозной smoke прошёл.
  Это не заменяет отдельный полный аудит доступности.
- Тёмная тема, серверный поиск, пагинация и установка сторонних навыков
  в этот этап не включены.
